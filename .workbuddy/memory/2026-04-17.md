## 2026-04-18 补充

### 用户详情 500 错误修复
- 错误现象：点击用户详情页显示"服务器内部错误"，GET /api/users/{id} 返回 500
- 根因：Spring Boot application.yml 配置了 Redis 密码 `123456`，但 Redis 服务端未设置密码
- 报错信息：`ERR Client sent AUTH, but no password is set`
- 临时解决方案：注释掉 application.yml 中 redis password 配置

### Redis 密码持久化配置
- Redis 安装位置：`F:\redis`
- 修改 `F:\redis\redis.windows.conf`，设置 `requirepass 123456`
- 正确启动方式：`cd F:\redis && redis-server redis.windows.conf`（必须带配置文件）
- 恢复 application.yml 中 redis password 配置，重启 Spring Boot 后端，问题完全解决
